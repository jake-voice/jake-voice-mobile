PROFILE · 履历

设计即表达
作品即语言

深耕工业产品研发与光影设计二十载。贯通平面系统、产品研发、古建保护、地标公建、城市夜游多领域实操经验。

我的价值，在于「全流程一致性」。大多数项目会在设计公司与工程团队之间出现断层，而我以单一设计师身份贯穿「概念 → ID → CMF → 3D → 渲染 → 结构对接 → 量产跟进」全链路，让每一个环节的决策都有据可依、有迹可循。

在照明领域，我既懂工业设计的严谨，也懂光影艺术的温度——曾与马岩松、崔愷等建筑大师合作过地标公建的光环境实践，也主导过中标四千万元的城市亮化 EPC 项目。
